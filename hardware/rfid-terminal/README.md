# MakerVault RFID/NFC Handheld — Rev3 mechanical release pack

**Status:** user-reported physically printed and fitted, including revised ESP32 cradle and USB retention bridge secured using **M2 screws directly into printed plastic**. Firmware is maintained separately in MakerVault-Hardware.

The current package contains:
- `STLs/` — current printable single-material parts and separately named bezel colour components
- `STEPs/` — editable STEP geometry corresponding to the current required parts
- `3MF/` — print-ready three-colour MakerVault bezel assembly
- `CAD_Sources/` — originating CadQuery Python scripts and original notes (may include superseded reference geometry)
- `BUILD_GUIDE.md` — parts, fasteners, orientation, assembly and validation
- `BOM.md` — physical parts, screw/insert notes and current printed files
- `WIRING.md` — exact GPIO-to-module pin table and text schematic for Rev C.3
- `SHA256SUMS.txt` — checksums for the packaged individual files

**Print exactly the current parts listed in BUILD_GUIDE.md**; do not mix older rear shells or encoder designs with the revised ESP32 bridge.
