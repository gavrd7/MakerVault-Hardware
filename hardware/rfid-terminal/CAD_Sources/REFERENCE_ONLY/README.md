# Reference / legacy geometry

The original CAD archives include older reference parts such as rear_fastening_revC and 12 mm knob geometry. These are not in the current required printable set. Use only the STEP files at the top-level STEPs folder when editing current parts. Current rear housing + bridge are from ESP32_Cradle_RevC_M2; current switch carrier is Rev E; current knob is Rev D.

For editable scripted designs, consult the archived source .py files under CAD_Sources. Regenerating them may require CadQuery and may create reference or superseded variants.
